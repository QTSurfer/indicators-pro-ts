Accelerator Oscillator, Awesome Oscillator, Know sure thing, Relative Vigor Index and Stochastic Oscillator take their simple averages as moving averages by default, as the Java engine does since 1.0.0-alpha.27. The values of these five change. A final `true` (`awesomeOscillator("ao", 3, 8, true)`, and the same in the other named forms) keeps the discrete averages of the earlier versions. Connors RSI's percent rank counts the other values of the window strictly below the current rate of change, so it runs from 0 to 100 and ties count as not below.
